Online Government Job Form Filling Guide 2026

Complete step-by-step instructions for SSC, IBPS, Railway, Police online applications

How to Fill Government Job Online Application Forms

All government job applications (SSC, IBPS, Railway, Police) are now online. This guide walks you through each step: registration, form filling, document upload, fee payment, admit card download.

Key Facts: All applications online (no offline). Need: Email, Aadhaar, 10th/12th/Degree certificate. Time required: 30–45 min per form. Save before submitting. Download confirmation.

Step-By-Step Application Process

Step 1: Register & Create Login (5 min)

  1. Visit official website (SSC.gov.in, IBPS.in, RRB.gov.in, state PSC).
  2. Click "Register" or "New Registration".
  3. Enter: Email, mobile, date of birth, Aadhaar (as per 10th certificate).
  4. Create password (mix uppercase, lowercase, number, symbol).
  5. Verify email (OTP sent to email).
  6. Registration complete. Login with email & password.

Step 2: Fill Personal Details (10 min)

  1. Date of birth (must match 10th certificate exactly).
  2. Full name (as per Aadhaar/10th certificate).
  3. Gender, category (General/OBC/SC/ST), nationality.
  4. Father/Mother name.
  5. Address (current + permanent, postal code required).
  6. Mobile + email (for communication).
  7. Save & proceed.

Step 3: Fill Educational Qualification (10 min)

  1. Highest qualification (10th/12th/Graduate).
  2. Exam year, board/university name, roll number.
  3. Stream (Science/Commerce/Arts) if applicable.
  4. Percentage/CGPA (even if not required, fill if known).
  5. For Diploma/Bachelor's: College name, university, passing year.
  6. Upload documents: 10th mark sheet, 12th mark sheet, Degree certificate (PDF, <500KB).

Step 4: Upload Documents (15 min)

  1. Photograph: Passport size (JPG/PNG, 4×6 cm, <200KB). Recent, colored.
  2. Signature: Black ink on white paper (JPG, <200KB).
  3. 10th mark sheet: Scan both sides (PDF, <300KB).
  4. 12th/Degree certificate: Official certificate (PDF, <300KB).
  5. Category certificate (SC/ST/OBC): If applicable (PDF, <300KB). Not older than 1 year.
  6. PwD certificate (if applicable): Medical certificate (PDF).
  7. Each file upload: Check format (only JPG/PDF allowed). Verify size before upload.

Step 5: Fill Exam Details (5 min)

  1. Select exam preference (SSC CGL / CHSL / IBPS PO / Clerk, etc.).
  2. Choose preferred exam center/location (important for logistics).
  3. Language of exam (English/Hindi/Regional).
  4. Optional subject (if applicable, e.g., UPSC IAS).

Step 6: Review & Payment (5 min)

  1. Review all details: Any mistake? Go back & correct before paying.
  2. Application fee: General/OBC ₹0–₹600 (varies by exam). SC/ST/PwD ₹0.
  3. Payment mode: Online only (credit/debit card, net banking, UPI).
  4. Pay securely. Get payment reference number.
  5. Do NOT close page until "Success" message appears.

Step 7: Download Confirmation (2 min)

  1. After payment success, download confirmation PDF.
  2. This is your proof of application. Save & print for records.
  3. Application reference number: Note this (needed for admit card download).

Common Mistakes to Avoid

  • Wrong date of birth: Must match 10th certificate exactly. No correction after submission.
  • Spelling errors in name: Government ID must match exactly.
  • Wrong category selected: Can't change after submission.
  • Photograph/Signature rejected: Upload clear, recent photos. <200KB. No filters.
  • Payment failed but page closed: Check email for confirmation. Contact support if not received.
  • Filling from shared WiFi: Use private internet. Public WiFi may disconnect mid-form.
  • Submitting without review: Carefully review before paying. No edits allowed after submission.

Documents Checklist Before Starting

  • ☐ Aadhaar card (copy)
  • ☐ 10th mark sheet (digital scan)
  • ☐ 12th/Degree certificate (digital scan)
  • ☐ Category certificate (SC/ST/OBC, if applicable)
  • ☐ Passport-size photograph (digital, <200KB)
  • ☐ Signature scan (black ink, <200KB)
  • ☐ Email ID (for receiving updates)
  • ☐ Mobile number (for OTP verification)
  • ☐ Credit/Debit card or online banking (for payment)
