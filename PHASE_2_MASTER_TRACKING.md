- **Hero Section:** Gradient background, quick facts (4-stat grid)
- **Main Content:** 6-8 sections with H2 hierarchy

## Internal Linking Strategy

### Hub-and-Spoke Architecture
- **Hubs:** Qualification index, Salary guides index, Comparisons index
- **Spokes:** Individual qualification/salary/comparison pages
- **Cross-Links:** Qualifications ↔ Salary Guides, Qualifications ↔ Comparisons

### Link Density Target
- Each page: 5-10 internal links minimum
- Related sidebar widgets: 4-6 links per page
- Footer links: 8-12 cross-section links

### Anchor Text Strategy
- Use target keyword for primary link (e.g., "B.Tech Government Jobs")
- Use descriptive text for secondary links (e.g., "Explore MBA career paths")
- Avoid over-optimization (stay below 2-3% keyword density)

## Risk Mitigation

### Content Quality
- **Risk:** Content becomes generic/templated
- **Mitigation:** Review each page for unique insights, real salary data, actual exam details

### Internal Linking
- **Risk:** Broken links or 404s
- **Mitigation:** Test all links after publication, use relative paths consistently

### Keyword Cannibalization
- **Risk:** Multiple pages targeting same keyword
- **Mitigation:** Ensure each page targets unique primary keyword (see TAM list)

### Deployment Issues
- **Risk:** Pages don't render properly, schema errors
- **Mitigation:** Test on staging environment before production, validate schema with Google tools

## Notes & Learnings

### Content Insights
- B.Tech pages should emphasize GATE exam pathway (highest-paying route)
- MBA pages should highlight fast-track to management roles
- M.Sc pages should focus on research fellowships and Ph.D. pathway
- B.Com pages should stress banking exam advantage and audit career
- Salary guides should include comparison with private sector

### Technical Observations
- Related jobs widget needs actual recruitment slugs (query database)
- Breadcrumb navigation should work with dynamic and static routes
- Schema markup for FAQ and JobCollection important for SERP features

### SEO Opportunities
- Each page can rank for 15-20 long-tail keyword variations
- FAQ sections capture "people also ask" snippets
- Internal linking creates content clusters for topic authority
