# Architecture changelog

Change-control record for the Controlled Architecture Implementation
Protocol. One entry per change, newest last. Entries are append-only: a
correction is a new entry that references the one it corrects.

Rules that apply to every entry:

- A schema change is always a migration file, never a manual edit.
- Destructive cleanup never ships in the same change as its replacement.
- If a change needs a new architectural decision, it stops and is reported
  under "Open decisions" instead of being decided here.

## SEO-001 Step 3 — pre-check (NOT STARTED; decision needed)

   listings (`/`, `/jobs`, …) when a visitor chooses Hindi. Under decision D3

   users who switched language.
